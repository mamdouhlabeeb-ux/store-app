إعداد أول مرة — خطوتين وخلاص

الأداة دي محتاجة "مكان تخزين سحابي" مجاني عشان تشتغل من أي جهاز مع كل الفروع. اعمل الخطوات دي مرة واحدة بس، وبعدها ابعت الملف لكل الفروع وهيشتغل عادي.

1 اعمل مشروع Firebase مجاني

ادخل على console.firebase.google.com بحساب Google بتاعك → Add project → سمّي المشروع أي اسم (مثلاً raven-branches) → كمّل الخطوات الافتراضية لحد ما يتعمل.

2 فعّل قاعدة البيانات (Firestore)

من القائمة الجانبية: Build → Firestore Database → Create database → اختار Start in test mode → اختار أقرب location وكمّل.

3 سجّل تطبيق ويب واخد بيانات الاتصال

من الترس ⚙️ جنب "Project Overview" → Project settings → في تبويب General انزل لـ "Your apps" → دوس على أيقونة </> (Web) → سمّي التطبيق أي اسم → هيديك كائن اسمه firebaseConfig فيه apiKey, authDomain... انسخه كله.

4 حط البيانات في الملف

افتح ملف branch_inventory_app.html بأي محرر نصوص (Notepad كفاية)، دور على الجزء ده في أول الكود:

const firebaseConfig = {
  apiKey: "PASTE_YOUR_API_KEY_HERE",
  ...
};

واستبدل القيم كلها بالقيم اللي نسختها من فايربيز، احفظ الملف، وحدّث الصفحة.

5 افتح صلاحيات القراءة/الكتابة

من Firestore Database → Rules حط القواعد دي بدل الموجودة واعمل Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

ملحوظة أمان: القواعد دي بتخلي أي حد يعرف بيانات المشروع (apiKey) يقدر يوصل للداتا مباشرة — مفيش سيرفر خاص بيتحقق من الباسورد غير باسورد الفرع جوه التطبيق نفسه. متشاركش الملف أو الـ apiKey في أماكن عامة، وده أقصى حماية ممكنة من غير باك إند حقيقي.
